Este módulo extiende la funcionalidad de los lotes de stock para añadir un campo que enlaza documentos con el mismo nombre y un botón para abrirlos directamente.

**Table of contents**

.. contents::
   :local:

Usage
=====

1. Ve a un lote de stock (Inventario > Lotes/Series).
2. Selecciona el documento en el campo "Documento" (se filtra automáticamente por nombre coincidente).
3. Haz clic en el botón "Abrir Documento" para ver el documento en su vista (como en la kanban de documentos).
